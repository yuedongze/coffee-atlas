---

Build a small planned set of parameter combinations around a repeatable baseline. Attach lot, machine, template version, measurements, rest age, and blind sensory results to each run; include repeats.

## Why it matters

A profile matrix makes comparisons traceable and supports data-informed decisions.

## A small experiment

Start with two settings of one parameter and repeated baseline runs; compare against predefined cup criteria before expanding.

## A misconception to question

> A matrix of unreplicated roasts proves which parameter caused a flavor.
